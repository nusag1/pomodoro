# ポモとごほうび

やることを登録して、25分集中 → 5分休憩（4回ごとに長い休憩）。できたらポイントがたまって、自分で決めた「ごほうび」と交換できる TODO アプリです。

- 使う：https://nusag1.github.io/pomodoro/
- スマホのホーム画面に追加すると、アプリのように使えます（オフラインでも開けます）
- データはこの端末のブラウザ（localStorage）の中だけに保存します。サーバーには何も送りません。設定画面からJSONで書き出し・読み込みができます

## しくみメモ（開発用）
- 1ファイル（`index.html`）＋ `sw.js`（オフライン用）＋ `manifest.webmanifest`
- タイマーは終わる時刻（`timer.endsAt`）を保存し、`Date.now()` との差で残りを出す。裏にいた間に集中も休憩も終わっていたら、`reconcile()` が終わった時刻どおりに順に進める
- `log[]` に1回ごとの記録（種類・タスク・予定時間・開始/終了・完了したか・一時停止回数）を残している。見積もりと実績の比較、連続日数・ふり返り、離脱検知はここから作れる。タスクには「今日の3つ」用の `today` 欄を予約済み
- テスト用：`?fast=300` で時間が300倍速になり、`window.__pomo` が使える
- `sw.js` を変えたら `VERSION` を上げる
